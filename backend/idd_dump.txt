4.3 Mode Selection Command (Msg ID: 0x02)
The Mode Selection command toggles the simulator between Simulation Mode and Radiation Mode. In Simulation Mode, the operator can load captured waveforms (e.g. Vivado ILA CSV or I/Q files), inspect time-domain signals, spectrum, and constellations, and stream samples to any carrier. In Radiation Mode, DACs transmit over-the-air with safety interlocks.

4.7 Command Acknowledgment Frame (ACK, Packet Kind: 0xBB)
The simulator answers every valid received command with an Acknowledge (ACK) frame within the configured ACK timeout (default: 2.0 s). In the ACK frame header, Destination ID and Source ID are reversed (Destination=0x01, Source=0x02), Message Counter matches the command sequence counter, Packet Kind is set to 0xBB, and Command ID matches the received command. The single-byte payload reports the execution status code.
